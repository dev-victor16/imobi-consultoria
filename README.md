# Imobi Consultoria Imobiliária 🏢✨

> Plataforma institucional e catálogo digital de alto padrão para a **Imobi Consultoria Imobiliária**, sediada em Ibirité - MG e com atuação em toda a Região Metropolitana de Belo Horizonte.

---

## 🌟 Visão Geral

Desenvolvido sob medida para proporcionar uma experiência visual sofisticada, fluida e com padrão editorial imobiliário, eliminando clichês de templates genéricos e valorizando a credibilidade, o portfólio de imóveis e a facilidade de contato via canais diretos.

### 📐 Destaques do Projeto
- **Design System Autoral**: Paleta em tons terrosos, verde institucional e dourado acobreado com tipografia premium (`DM Serif Display` + `Inter`).
- **Ritmo Visual e Quebras de Seção**: Hero imersivo com busca rápida integrada, carrossel de lançamentos em destaque, grid de categorias e faixa de impacto com fotografia de arquitetura.
- **Microinterações & Animações**: Transições suaves a 60fps, animação de contadores numéricos, efeito parallax e scroll reveal progressivo.
- **Responsividade Total**: Layout adaptável para smartphones, tablets, notebooks e monitores ultrawide.
- **Foco em Conversão**: Acesso rápido ao WhatsApp corporativo, botão flutuante, canais diretos por setor e formulário de contato integrado.

## 🚀 Como Executar Localmente

Como o projeto é construído em Vanilla HTML5, CSS3 e JavaScript puro, não requer instalação de dependências ou build:

1. Clone o repositório:
   ```bash
   git clone https://github.com/dev-victor16/imobi-consultoria.git
   ```
2. Abra a pasta do projeto e dê dois cliques no arquivo `index.html` ou use uma extensão de Live Server.
